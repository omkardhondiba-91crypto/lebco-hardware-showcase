Create a **simple, classic, professional business website**.

The website should look like a genuine established Indian hardware business website.

It should NOT look like:

* A SaaS startup
* An AI startup
* A technology company
* A gaming website
* A personal portfolio
* A trendy startup landing page
* A flashy marketing website

Think:

**Professional hardware catalogue + traditional business website + modern clean UI.**

The priority is:

**Clarity > Decoration**

**Professional > Trendy**

**Classic > Experimental**

**Simple > Flashy**

**Product information > Animation**

**Usability > Visual effects**

# 4. ANIMATIONS — KEEP THEM MINIMAL

Do NOT overuse animations.

The website should feel calm, stable and professional.

Avoid:

* Parallax scrolling
* Animated backgrounds
* Large text animations
* Constant movement
* Excessive fade-ins
* 3D effects
* Complex scroll animations
* Excessive hover effects
* Floating animated cards
* Flashing elements
* Excessive page transitions
* Unnecessary loading animations

Only use subtle animations when useful:

* Small button hover
* Subtle product-card hover
* Smooth scrolling
* Simple mobile-menu transition
* Very subtle section fade-in if necessary

The website should look professional even with animations disabled.
